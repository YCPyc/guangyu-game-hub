老师说明

配套第 3 节《AI 对人际连接的影响》，教材第 62–64 页。理解交流方式的作用取决于情景、双方需要和偏好。

  1. 导入（2 分钟）：说明规则，请学生尊重不同交流偏好。
  2. 情景选择（8 分钟）：逐题朗读，全班举手表达意见，邀请不同观点说明理由，老师代选一种课堂意见；平票时先讨论再决定。
  3. 总结（3–5 分钟）：逐题回顾解释，讨论最高分是否一定意味着更好的人际关系。可再次体验比较情景差异，不做学生排名。
  4. 导出（1 分钟）：填写班级与参与人数，下载 PNG 或 CSV。未完成时导出会标注进度。

本活动只记录老师代选的课堂观点，不代表每位学生的答案；不收集学生个人信息。

课堂选择是全班讨论后的代表观点，积分不对应任何学生。

本游戏完全离线可用，不收集任何学生信息。
